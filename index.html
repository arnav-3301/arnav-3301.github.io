Selected Projects

Kilo Text Editor

Tech Stack: C, POSIX API (termios), GNU Make

A minimalist, dependency-free terminal text editor built from scratch in C to explore low-level POSIX terminal control, raw mode state management, and custom memory buffering.

  • Terminal Management: Interfaced directly with the termios structure to transition the terminal into Raw Mode, safely parsing raw byte input and overriding default signal processing.
  • Rendering Optimization: Engineered a dynamic append buffer to consolidate ANSI escape sequences and text updates into a single atomic write() call, eliminating terminal screen flicker.
  • Syntax Engine: Implemented a state-driven syntax highlighting system with dynamic filetype detection, tracking byte-level text properties and multi-line comment states across render cycles.
  • Interactive Systems: Built a callback-driven prompt system supporting safe file I/O operations and an incremental search engine with real-time visual highlighting and traversal.

0x88 Chess Engine

Tech Stack: C++, Raylib, POSIX API

A high-performance, single-threaded C++ chess engine featuring a decoupled MVC architecture that separates core board physics from a fully interactive graphical application suite.

  • AI & Search Engine: Developed a Minimax AI utilizing Alpha-Beta Pruning, MVV-LVA move ordering, and Zobrist Hashing (Transposition Tables) to achieve 14+ Million nodes per second.
  • 0x88 Architecture: Engineered lightning-fast pseudo-legal and strict legal move generation, mathematically verified against a 3.19 billion node Perft benchmark.
  • System Integration: Built a native Linux application hub utilizing POSIX fork() and execl() for seamless process replacement between visual gameplay and headless arena targets.
  • State Management: Implemented O(1) Threefold Repetition detection and a randomized Opening Book library to eliminate deterministic engine loops.
